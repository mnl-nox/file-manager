# Documentacao do projeto

Esta pasta concentra a documentacao tecnica inicial do File Manager em C.

O repositorio esta em fase de definicao: os diretorios `src/`, `include/`,
`ui/` e `data/` ainda nao possuem implementacao. Os documentos abaixo
registram a proposta funcional e tecnica que deve orientar a implementacao.

## Documentos

- [Objetivos](objetivos.md): finalidade, escopo e requisitos iniciais.
- [Requisitos](requisitos.md): requisitos funcionais (RF) e nao funcionais (RNF).
- [Arquitetura](arquitetura.md): organizacao dos componentes e fluxo da aplicacao.
- [Modelo](modelo.md): entidades, operacoes e estruturas de dados previstas.
- [Modelagem](modelagem.md): modelo de dominio, fluxo de dados e estados.
- [Decisoes](decisoes.md): registro das decisoes tecnicas do projeto.
- [UML](uml.md): diagramas de casos de uso, componentes e sequencia.
- [Stack](stack.md): tecnologias, ferramentas e dependencias planejadas.

## Referencia de desenvolvimento

A organizacao segue uma referencia SLDC (Software Development Life Cycle):

1. Levantamento dos objetivos e requisitos.
2. Modelagem do dominio e das interfaces.
3. Definicao da arquitetura e da stack.
4. Implementacao incremental.
5. Validacao com testes e revisao.
6. Documentacao e evolucao.

A referencia de codigo indicada para o projeto e o repositorio
[c-lab](https://github.com/mnl-nox/c-lab).
