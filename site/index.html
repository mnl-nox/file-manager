04 — TRUST BOUNDARY

Segurança não
é decoração.

As operações finais usam descritores de diretório. No Linux, a resolução do diretório pai usa openat2 com RESOLVE_NO_MAGICLINKS quando disponível. Links simbólicos comuns continuam permitidos nos componentes intermediários.

! O File Manager não é uma sandbox. Opera com as permissões do usuário atual. Em kernels sem openat2, o fallback não oferece a mesma proteção contra magic links.
